# Universe Coin (UC) 정책 가이드

> **1 UC = 1 KRW** | 탈퇴 시 소멸 | 재가입 시 0 재시작
> 사용: 결제 건별 최대 10% UC 차감 (현금 환급 불가)

---

## 정책 원칙

| 원칙 | 내용 |
|------|------|
| **가치 비례** | 유니버스에 기여한 가치가 클수록 많이 지급 |
| **남용 방지** | 월별 횟수 상한(monthly_cap) 전 액션에 적용 |
| **서비스 연동** | 특정 서비스 전용 코인은 해당 brand_id 지정 |
| **전 브랜드 공통** | brand_id = NULL → 어느 서비스에서 발생해도 동일 지급 |
| **일회성 구분** | 전체 1회(GLOBAL) vs 브랜드별 1회(PER_BRAND) — 아래 표 참조 |

---

## 일회성 vs 월 한도 구분

> **일회성 액션은 monthly_cap과 별개로 DB에서 이중 지급을 차단한다.**

| 구분 | 설명 | 해당 액션 |
|------|------|-----------|
| **전체 1회 (LIFE_ONCE_GLOBAL)** | 계정 생애 1회. brand_id 무관. | `signup_complete`, `profile_complete`, `profile_advanced` |
| **브랜드별 1회 (LIFE_ONCE_PER_BRAND)** | 브랜드당 1회. 다른 브랜드에서 다시 가능. | `first_purchase`, `service_onboard` |
| **월 한도 (MONTHLY_CAP)** | 매월 리셋. monthly_cap 횟수만큼 적립 가능. | 나머지 모든 액션 |

## 사용(Redeem) 정책

> **10% 한도는 결제 건별 적용.** 같은 달에 여러 서비스, 여러 모임에 각각 10% 사용 가능.

| 서비스 | 최대 UC 사용 비율 | 예시 |
|--------|----------------|------|
| Badak 모임 | 10% (건별) | 3만원 모임 A → 3,000 UC / 3만원 모임 B → 3,000 UC (각각) |
| WIO 구독 | 10% (건별) | 14.9만/월 → 최대 14,900 UC |
| SmarComm | 10% (건별) | 동일 |
| Planners 교육 | 10% (건별) | 동일 |
| NatureBox 구매 | 10% (건별) | 동일 |

## 금액 적절성 검토

### 기준점: 1 UC = 1 KRW, 사용 한도 10% (건별)

| 상황 | 계산 | 판단 |
|------|------|------|
| 바닥 모임 3만원 참여 → 5,000 UC → 다음 모임 10% 할인 | 5,000원 혜택 / 3만원 모임 = 환급률 16% | ✅ 체감 괜찮음 |
| 스토리 작성 5,000 UC = 5,000원 | 1시간+ 작성 노력 대비 5,000원 | ⚠️ 동기부여 약할 수 있음 |
| 게시글 500 UC = 월 5개 써서 2,500원 | 글 5개에 2,500원 | ⚠️ 너무 낮음 |
| 친구 초대 2회 = 8,000 UC | 신규 유저 2명 확보 비용 8,000원 | ✅ CAC 대비 합리적 |
| WIO Pro 14.9만/월 → 14,900 UC로 10% 할인 | 한 달 꽉 채워도 14,000 UC = 93% 달성 | ✅ 설계 의도에 부합 |

### 조정 권고안 (미적용, 검토 중)

| 항목 | 현재 | 권고 | 이유 |
|------|------|------|------|
| `write_post` 게시글 | 500 UC | **1,000 UC** | 커뮤니티 활성화 |
| `write_comment` 댓글 | 200 UC | **300 UC** | 소폭 상향 |
| `post_viral` 바이럴 글 보너스 | 없음 | **2,000 UC** | 퀄리티 글 장려 |
| 굿즈·소액 이벤트 사용 한도 | 10% | **30~50%** | 체감 혜택 강화 |
| 스토리 금액 | 5,000 UC | **유지** | 코인보다 노출 가치 강조 |

> 핵심 설계 원칙: **코인이 "유니버스를 쓸 이유"가 되어선 안 된다. 유니버스를 쓰다 보면 코인이 쌓이는 구조**가 맞다.

### 중복 지급 방지 로직 (`lib/supabase/uc.ts`)
```
LIFE_ONCE_GLOBAL  → member_id + action_key 존재 여부 확인
LIFE_ONCE_PER_BRAND → member_id + action_key + brand_id 존재 여부 확인
MONTHLY_CAP → 이번 달 member_id + action_key + brand_id 횟수 확인
```

### 운영 가이드

| 상황 | 처리 |
|------|------|
| 부정 사용 의심 | 인트라 > UC > 트랜잭션 조회 → `admin` 타입 음수 트랜잭션으로 차감 |
| 프로모션 (2배 이벤트) | `uc_earn_rules` INSERT (valid_from/valid_until 지정, label에 이벤트명) |
| 코인 만료 정책 | 현재 미적용. 필요 시 `expire` 타입 트랜잭션으로 처리 |
| 환급 불가 원칙 | UC는 현금 전환 불가. 유니버스 내 사용만 허용 |
