# HeRo 64 유형 디자인 시스템

> 64 캐릭터 일러스트·배지 제작을 위한 단일 진실 소스.
> 이 문서의 규칙을 따르면 64개가 하나의 세계관으로 묶인다.

---

## 1. 월드 컨셉

### 1.1 설정

**"현대 직업군 Pantheon"** — 64명의 영웅이 각자의 현실 직무 원형을 상징한다.
판타지 왕·요정·동물 의인화 금지. 전원 **현대적이고 실제적인 인간 캐릭터**.

### 1.2 세계관 원칙

| 축 | 결정 |
|----|------|
| 시대 | 현대 (2020년대 이후) |
| 장소감 | 도시·오피스·스튜디오·연구실·필드 등 현대 직장 맥락 |
| 성별 | 남성/여성 각 32명씩 배분 (DISC 그룹별 균형) |
| 인종·외모 | 다양성 확보 — 한국인 편중 지양 |
| 연령 | 25~45세 범위 (직업적 원숙기) |
| 옷차림 | 각 직무 원형에 맞는 현대 복장 (수트·작업복·캐주얼·연구복 등) |
| 감정 | 긍정·집중·자신감 — 부정·냉소·공격 금지 |

## 2. 스타일 가이드

### 2.1 아트 스타일

**만화풍(Modern Semi-Realistic Cartoon)** — 픽사·카툰 네트워크의 중간 지점.
- **굵은 아웃라인** (2~3px 일정)
- **납작한 그림자 처리 (2~3 tone)**, 그라데이션 최소화
- **피부톤**: 자연스럽되 약간 채도 높인 표현
- **배경**: 없음 또는 캐릭터 주변 1~2개 소품만
- **얼굴**: 눈·입·눈썹 명확, 감정 읽기 쉽게

### 2.2 Forbidden

- ❌ 사실적 사진 스타일 (realistic photography)
- ❌ 애니메 빅아이·소녀만화 스타일
- ❌ 픽토그램·아이콘 스타일 (너무 추상적)
- ❌ 3D 렌더·게임 CG 느낌
- ❌ 수채화·유화 질감

### 2.3 출력 포맷

| 에셋 | 용도 | 사이즈 | 포맷 |
|------|------|--------|------|
| 전신 일러스트 | 결과 리포트, 유형 상세 페이지 | 1024×1024 | WebP, 투명 배경 |
| 배지 심볼 | 프로필 카드, 공유 이미지 | 256×256 | WebP, 원 프레임 |

## 7. 제작 워크플로우

### 7.1 생성 순서

1. **W1**: 파일럿 4개 생성 → 스타일 승인/롤백
2. **W2~3**: DISC 그룹별 16개씩 생성 (D → I → S → C 순)
3. **W4**: 디자이너 리터치 (일관성 보정)
4. **W5**: 배지 심볼 64개 (전신 크롭·원 프레임)
5. **W6**: Storage 업로드 + DB `illustration_url` 기록

### 7.2 생성 도구

- **1순위**: Midjourney v7+ (일관성 높음, 스타일 고정 가능)
- **2순위**: DALL-E 3 (정확한 프롬프트 반영)
- **대체**: Stable Diffusion XL + LoRA (로컬 제어)

### 7.3 품질 검증 체크리스트

각 생성물마다:
- [ ] 굵은 아웃라인 2~3px 일정한가
- [ ] 그룹 컬러 팔레트가 메인으로 나오는가
- [ ] 포즈·표정이 그룹 가이드와 일치하는가
- [ ] 소품이 직무 원형을 말해주는가
- [ ] 부정적 감정(냉소·공격·우울) 없는가
- [ ] 64×64px로 축소해도 식별 가능한가
- [ ] 성별·인종 중립 분산에 기여하는가

### 7.4 Storage 구조

```
supabase://site-branding/hero/types/
  ├── full/
  │   ├── D-ENFJ.webp   (1024×1024)
  │   ├── D-ENFP.webp
  │   └── ... × 64
  └── badge/
      ├── D-ENFJ.webp   (256×256)
      └── ... × 64
```

**DB 기록 규칙**: `hit_hero_types.illustration_url`에 **전신 URL**만 저장.
배지 URL은 앱 레벨에서 경로 치환 (`full/` → `badge/`)으로 추출.

## 9. 문서 유지 관리

- 이 문서는 디자인 의사결정의 **SSOT**. 프롬프트·컬러·구조 변경 시 반드시 여기 먼저 반영 후 생성.

- 양산 중 발견된 이슈는 섹션 7.3 체크리스트에 추가.
- 로드맵·일정 업데이트는 `WORK_STATUS.md`·`ROADMAP.md`로.
