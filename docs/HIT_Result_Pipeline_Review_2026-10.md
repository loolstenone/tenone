# HIT 결과 도출·리포트 점검 + /hero/hit 상세 페이지 검토 (2026-10-12)

> 범위: HIT A·B·C·D·E·F·GAP — 문항 → 응답 저장 → 채점 → 결과 저장 → 결과 API → 결과·보고서 화면, 그리고 /hero/hit 이하 소개·안내 문구.
> 방법: ① 코드 경로 정적 대조 ② 운영 DB 문항(읽기 전용)으로 가상 응답(전부 높음·전부 낮음·중간)을 만들어 채점 함수·리포트 모듈 선택까지 실행 (scratchpad `hit-harness.mts`, DB 쓰기 없음).
> 전제: HIT 재편 마이그레이션(`sql/hit-restructure-2026-10.sql`)은 **승인 전** — 하네스는 재편 후 체계를 코드로 흉내 내 검증했다.

### 그 밖의 결함 (수정 완료)
- **D~F·GAP는 사실상 시작이 불가능했다**: DB `hit_sessions.test_type` CHECK가 A·B만 허용(마이그레이션 1항에서 해제), 문항 module(`layer_x`)과 화면 모듈 이름이 달라 0문항 출제(재편 커밋에서 sub_domain 매핑으로 수정), `?a=` 없으면 세션·채점 실패 → 본인 최신 A로 대체(남의 A id는 거부).
- **AI 모델 ID**: D~GAP가 존재하지 않는 ID(`claude-sonnet-4-5-20250514`)를 써서 AI 해설이 항상 실패 → `lib/hit/ai.ts` 단일 설정.
- **채점 순서**: 체크리스트 준비도를 채점 뒤에 덮어써서 갭 영역("이직 준비 보강 필요" 항상 표시)·차기 역할(현재 위치)·복귀 경로 근거가 0 기준으로 계산 → 채점 함수가 체크리스트 완료율(그룹별)을 직접 받음.
- **척도 바닥 불일치**: CH·AP는 합/(n×7)로 최저 14, 나머지는 (평균−1)/6로 최저 0 → 전부 (평균−1)/6.
- **A '다크 트라이어드' 사전 플래그**: 주도성 문항 4개로 성격장애 경향을 추정 — 타당도 근거 없음·미고지 → 폐지 (응답 성실도 신호만 유지, /hero/hit/method 5항에 고지).

## 2. 결과는 이렇게 만들어진다 — HIT 엔진 (브랜드화)

`/hero/hit/method` 공개 페이지 신설 (회원 게이트 밖). 내용은 코드와 같아야 한다:

1. 문항 — 7점 척도 단일 형식, 영역 안 순서 섞기, 역문항, 상태형 항목은 체크리스트로 분리
2. 채점 — 서버 규칙(재현 가능), (평균−1)/6×100, 성격 4축 비율·행동 상대 비중, S-Power 가중합(UF 제외), 흥미×효능 매트릭스, CVI 35/35/30
3. 해설 — 검수된 리포트 모듈 324개, 점수 구간 67/34로 선택 (`lib/hit/stage-report-modules.ts`, `lib/hit/report-assembler.ts`)
4. AI — 읽기용 요약만, 점수·유형·모듈 선택을 바꾸지 않음, 실패해도 결과 완결, 이름·연락처 미전달
5. 응답 품질 — 성실도 신호는 운영자만, 결과·매칭에 불이익 없음
6. 개인정보 — 회원 전용, 본인·운영자만 열람, UF는 매칭 미사용, 종교 미질문, 통계는 익명
7. 검증 계획 — α ≥ 0.70 목표·재검사·요인분석·공정성. **"검증 완료"라고 쓰지 않는다** (데이터 0건, 표시광고법)
- HIT를 읽을 때: 자기보고 · 유형은 경향 · 채용 단독 판단 근거 아님 · 기업에 미제공

결과 화면(C~GAP)에도 "HeRo 해설(규칙 기반)"과 "종합 해설(AI 보조)"을 분리 표기하고 HIT 엔진 링크를 둔다.

### 남은 확인·결정
- **마케팅 직무 트랙 문항 없음**: `hit_competency_tracks` 22개 중 광고 기획·브랜드 매니지먼트·콘텐츠 마케팅·마케팅 전략·퍼포먼스 마케팅 5개는 B 트랙 역량·C 트랙 준비도 문항이 0개. MADLeague·MADLeap 회원 다수가 고를 트랙이라 우선 작성 필요 (트랙당 역량 30 + 준비도 12).
- 마이그레이션 승인 후 운영에서 회원 계정으로 A→B→C~GAP 실제 1회씩 완료 확인.
- AI 해설: Anthropic 크레딧 상태 확인 (WORK_STATUS 세션 167 — 크레딧 고갈 이력). 실패해도 결과는 규칙 기반으로 완결된다.
