## 1. TenOne AI Team 구조

```
열시일분 (L0 — 기획·취합·판단)
    └── Mindle (L1 — 조사·분석·콘텐츠 제작)
            └── 브랜드 에이전트 (L2 — 채널별 운영)
                MADLeague / MADLeap / Badak / YouInOne 등
                        └── 봇 (L3 — 채널 접점)
                            쇠봇 / 듣봇
```

### 역할 분담

| 레이어 | 에이전트 | 역할 |
|--------|---------|------|
| L0 | 열시일분 | 기획, 취합, 최종 판단 |
| L1 | Mindle | 조사·분석, Mindle 사이트 운영 및 콘텐츠 제작 |
| L2 | 브랜드별 | Mindle 분석 기반 각 채널 맞춤 콘텐츠 제작·브랜드 운영 |
| L3 | 쇠봇·듣봇 | 채널 최전방 접점 |

## 2. 봇 종류

### 쇠봇 (바당쇠)
- **역할**: 바닥 직영 오픈채팅방에서 활약. 유용한 정보 제공 + 방장 보조
- **성격**: 발신형 (능동적 참여)
- **담당 채널** (7개):

| 방 이름 | 별칭 | 성격/톤 |
|---------|------|---------|
| 수다방 | 바당쇠 | 친근하고 유머러스, 커뮤니티 분위기 메이커 |
| 디지털 마케팅방 | 디마 | 전문 지식 중심, 신뢰감 있는 톤 |
| 레퍼런스방 | 레퍼 | 큐레이터형, 출처 명시 |
| 취업이직정보방 | 헌터 | 공감 먼저, 실용 정보 제공 |
| CR방 | CR | 간결하고 실용적 |
| 팀장방 | 팀원 | 격식체, 리더십 관점 |
| 자료 공유 | 다리 | 자료 정리·공유 보조 |

### 듣봇
- **역할**: 타인이 운영하는 외부 오픈채팅방에 사람처럼 입장해서 **듣기만** 함
- **성격**: 수신형 (완전 수동적)
- **대상 영역**: 경영, 마케팅, 광고, 서비스, 디자인, 창업, 부동산 등
- **특이사항**: 방마다 입장 조건, 네이밍 조건 다름
- **출력**: 수집 내용 → Mindle 데이터 파이프라인으로 전달

## 4. 기술 구현 방향

### 핵심 리소스
- **공기계 (Android)**: 쇠봇·듣봇 전용 상시 가동 디바이스
- **별도 카카오 계정**: 이미 여러 방에 입장 완료 ✅ (가장 큰 허들 해결됨)

### 구현 방식: open.kakao.com + Playwright

```
공기계 (항상 켜둠, 충전기 연결)
  └── Chrome → open.kakao.com (별도 계정 로그인)
        └── Playwright 스크립트 (세션 유지)
              ├── 메시지 모니터링 (폴링 or WebSocket)
              ├── 트리거 감지 (멘션, 키워드, 질문형)
              └── 응답 전송
                    ↑
              TenOne API (/api/agent/badaksoe)
                    ↑
              Claude API (방별 시스템 프롬프트)
```

### 방별 시스템 프롬프트 분기

```python
ROOM_PERSONAS = {
    "수다방": "친근하고 유머러스. 바닥 커뮤니티 분위기 메이커. 짧고 가볍게.",
    "디마":   "디지털 마케팅 전문가. 신뢰감 있는 톤. 출처 있으면 함께.",
    "레퍼":   "레퍼런스 큐레이터. 링크·출처 명시. 한 줄 요약 먼저.",
    "헌터":   "취업·이직 공감 먼저. 정보는 구체적으로.",
    "CR":     "간결하고 실용적. 핵심만.",
    "팀장방": "격식체. 리더십·조직 관점.",
    "다리":   "자료 정리 보조. 파일·링크 공유 중심.",
}
```

## 6. 리스크 & 주의사항

| 항목 | 쇠봇 | 듣봇 |
|------|------|------|
| 카카오 탐지·차단 | 낮음 (직영 채널) | **높음** (외부 채널) |
| 계정 밴 리스크 | 낮음 | 중간~높음 |
| 개인정보 수집 | 해당 없음 | **검토 필요** |
| 방 규칙 위반 | 없음 | 방마다 다름 |
| 법적 리스크 | 없음 | 검토 필요 |

**듣봇은 기술보다 정책·기준 먼저 정리 후 개발.**
