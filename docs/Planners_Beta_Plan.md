# 플래너'스 AI 베타 실행 - 개발 계획

> 작성 2026-10-17 · 상태: **계획 (결정 대기 5건)** · 관련: `app/(Planners)/CLAUDE.md`, `lib/myverse/ai-access.ts`, `lib/paid-launch.ts`

## 0. 방향 (2026-10-17 사용자)

- 처음 오는 사람 = **그동안 만든 PAD 플래너를 받으러 오는 사람**. 그들이 플래너'스 AI를 써 보며, **지금 있는 AI 초기 버전부터 사용자가 인정하는 범위에서 조금씩 업데이트**해 간다
- 대상 = 하나하나 꼼꼼하게 일정을 정리하고 싶은 사람, 기록으로 남기고 싶은 사람 → **기능 만족**(빠짐없이·밀려도 다시 쓰지 않게·찾을 수 있게) + **감성 만족**(내 손으로 정리한 뿌듯함·쌓이는 기록)
- 가장 큰 걱정 = **사고 없이 작동하느냐**. 기록형 사용자에게 가장 큰 배신은 쓴 기록이 사라지는 것 → **0단계(안전)를 끝내기 전에는 베타를 열지 않는다**
- 결제 없음 (`PAID_LAUNCH` 꺼짐 그대로). 유료화는 베타가 끝난 뒤 따로 결정

```
PAD 다운로드 (로그인·Planner's 동의)
  → 받은 직후 "같은 구조로 플래너'스 AI도 써 보세요 (베타)"
  → 베타 참여 (한 번 누르기 + 베타 안내 동의) → AI 열림 (월 한도 안에서)
  → 앱 안 "의견 보내기"
  → 의견이 몰리는 곳부터 고치고, 새 기능은 '써 보기'로 먼저
  → 업데이트 소식 "의견으로 바뀐 것" → 다시 사용
```

## 1. 결정 대기 (사용자)

| # | 정할 것 | 추천 | 막히는 단계 |
|---|---|---|---|
| D1 | **Supabase Pro 전환** (월 $25) - 매일 자동 백업 7일, 사용량 한도 상향 | 런칭 전 전환. 지금 무료 요금제 = 자동 백업 없음 + 10-15 사용량 초과 메일 | 0단계 |
| D2 | **Anthropic 키·크레딧** 연결과 충전 방식 (자동 충전 또는 잔액 알림) | 베타 열기 전 연결. 10-14 로컬 키 무효 기록 | 1단계 |
| D3 | **베타 종료일** | 정하기 어려우면 "정식 출시 전까지" (상수 하나, 나중에 날짜로) | 1단계 |
| D4 | **한 사람당 월 AI 한도** | 전체 100회 + 손글씨·사진 30회 | 1단계 |
| D5 | **모델 교체 시험** (Haiku 4.5 → 5.5, Sonnet 4.6 → 5.5) | 손글씨 샘플로 품질 시험 후 결정. 통과하면 비용 약 1/3 | 3단계 (선택) |

예상 AI 비용 (2026-10-17 추정, 지금 모델): 1인 월 350~3,100원, 평균 약 890원 · AI 사용자 300명이면 월 약 27만 원. 월 100회 한도면 1인 최대 약 3,800원.

## 2. 단계별 개발

### 0단계 - 안전 (베타 열기 전 필수)

| # | 할 일 | 내용 | 확인 방법 |
|---|---|---|---|
| S1 | 백업 | D1 결정 후 Pro 전환 확인, 복원 절차 한 번 시험 (스테이징 아님 - 백업 목록 확인까지) | Supabase 대시보드 백업 목록 |
| S2 | **할 일 저장을 한 번에** | 지금 `myverse_daily.tasks`(jsonb 배열)를 읽어서 고친 뒤 통째로 다시 쓴다 → 휴대폰·PC 동시 편집 시 한쪽이 사라짐. DB 함수(행 잠금 + 배열 안 한 항목만 추가·수정·삭제)로 바꾸고 `app/api/myverse/daily/[date]/task/*`가 그 함수만 부른다 | 두 탭에서 동시에 추가·수정 → 둘 다 남는지 |
| S3 | AI가 실패해도 기록은 남게 | 생각 쏟아내기·손글씨에서 AI 오류(402·429·500·시간 초과) 시 쓴 글을 지우지 않고 "그대로 메모로 저장" 선택지 | 키를 일부러 틀리게 해서 확인 |
| S4 | 앱 화면 오류 #418 | `/planners/app` 첫 화면에서 서버·브라우저 글자가 달라지는 곳(날짜·시간 표시 추정) 찾아 고침 | 실서버 콘솔 오류 0 |
| S5 | 멈추면 알게 | `lib/intel/ops-health.ts`에 "못 끝낸 일 자동 다시 놓기"(결과물 = 다시 놓인 할 일 수)와 "Planner's AI 응답 실패율" 추가 | 인트라 Intelligence › 운영 상태 |
| S6 | 내보내기 | 설정 › 사생활 › 내보내기(`/api/myverse/data-export`)가 Planner's 기록(할 일·일정·노트·프로젝트) 전부를 받는지 | 실제 파일 열어 보기 |
| S7 | 첫인상 | 공유 미리보기 그림(첫 화면·PAD·AI 소개 og:image) · 카카오 로그인 버튼(정지 상태면 숨김) | 카톡 공유, `site:check` |
| S8 | **끝까지 눌러 보기** | 로그인 상태로 가입 → Planner's 동의 → 처음 설정 → 하루 쓰기(할 일·일정·노트·손글씨) → 다음 날 자동 다시 놓기 → 로그아웃. 휴대폰·태블릿 크기 포함 (사용자가 크롬에 로그인) | 점검 기록을 이 문서에 |

### 1단계 - 베타 참여

| # | 할 일 | 내용 |
|---|---|---|
| B1 | PAD → AI 안내 | PAD 다운로드 직후 한 줄 안내 "같은 연간·월간·주간·오늘 구조로 플래너'스 AI도 써 보세요 (베타)". 다운로드를 막지 않는다 |
| B2 | 베타 참여 | 앱 처음 설정 또는 AI 버튼에서 "베타 참여" 한 번 → 베타 안내 동의(무료·기능이 바뀔 수 있음·의견을 개선에 씀, 버전 기록) → `myverse_users` 구독 활성 + 만료일 = 베타 종료일(D3). 인트라 수동 지급(`/intra/planners`, 출처 '베타 테스터')은 그대로 둔다 |
| B3 | 월 한도 | `lib/myverse/ai-access.ts` 한 곳에서만 (라우트마다 따로 두지 않는 원칙 유지). `myverse_ai_usage`로 이번 달 횟수 계산, 넘으면 429 `ai_monthly_limit` → 화면 "이번 달 베타 사용량을 다 썼어요, ○일에 다시 열립니다". AI 없이 되는 기능은 계속 |
| B4 | 베타 문구 | 첫 화면·AI 소개·앱 안내를 베타 기준으로 ("AI 기능은 베타로 무료, 한 달 사용량 안에서"). 가격 문구 없음 (`<BetaPricingNotice />` 규칙) |
| B5 | AI 안내 화면 정리 | `AiPaidOnlyNotice`("유료 회원 전용") → 베타 참여 안내로 바꿈 |

### 3단계 - 조금씩 업데이트

| # | 할 일 | 내용 |

### 4단계 - 만족을 숫자로

인트라 Planner's 대시보드에 (집계 수만 - 개인 단위 교차 분석 금지):
- 계속 쓰나: 7일째·28일째 다시 와서 기록한 비율
- 기록이 쌓이나: 1인 하루 기록 수, 회고를 쓴 비율
- 기능이 돕나: 자동으로 다시 놓은 할 일을 그대로 둔 비율, 의견이 몰리는 화면
- PAD → AI: PAD 다운로드 회원 중 베타 참여 비율
