# HeRo 파일럿 4종 — AI 이미지 생성 프롬프트

> Midjourney v7+ / DALL-E 3 / Stable Diffusion XL 에 바로 붙여넣기 가능한 원샷 프롬프트.
> 설계 원칙은 [hero-types-design-system.md](./hero-types-design-system.md) 참조.

---

## 사용 순서

1. 아래 4개를 생성 도구에 각각 입력
2. DISC 4 그룹이 한 스타일로 묶이는지 확인
3. 부자연스러운 유형은 원본 프롬프트의 **Character / Pose / Props** 라인을 조정 후 재생성
4. 스타일 확정되면 섹션 하단 "양산 템플릿"으로 64개 확장

## 파일럿 검수 체크리스트

각 파일럿 생성 후 다음 항목 전부 통과해야 양산 진입:

### 스타일 일관성
- [ ] 4개를 나란히 놓았을 때 같은 사람이 그린 듯한가
- [ ] 아웃라인 굵기 일정한가 (2~3px)
- [ ] 그림자 tone 수가 동일한가

### 그룹 변별력
- [ ] D/I/S/C 그룹을 한눈에 구분 가능한가
- [ ] 그룹 컬러가 메인으로 드러나는가
- [ ] 포즈·표정이 그룹 가이드와 맞는가

### 유형 식별
- [ ] 소품이 직무 원형을 암시하는가
- [ ] 256×256px로 축소해도 식별 가능한가
- [ ] 64×64px로 축소해도 실루엣이 드러나는가

### 감정·다양성
- [ ] 전원 긍정 감정인가
- [ ] 4명의 성별·인종 배분이 자연스러운가
- [ ] 부정 고정관념(리더=백인남, 돌봄=여성) 피하는가

**하나라도 실패하면 해당 파일럿만 프롬프트 조정 후 재생성.**
