# HIT 결과 분석 전면 검토 + 검사 이름 반영 현황 (2026-10-12)

> 범위: HIT - Archetype(A) · Bounce(B) · Challenger(C) · Departure(D) · Elevate(E) · Flourish(F) · Gap(G)
> 방법: 채점 → 저장 → 해설 모듈 선택 → 화면 문구를 코드로 대조하고, 운영 DB 더미 결과(A·B·C 4명, D·E·F·G 1건씩)로 실제 선택된 해설을 확인

## 1. 검사 이름(브랜딩) 반영 위치

표기 원칙: 제목 = `HIT - Archetype`, 부제 = 상황 설명(나에 대한 이해 …), 글자(A~G)는 작은 배지에만. 원천은 `lib/hit/stages.ts` 한 곳 (`code`·`brand`·`letter`·`name`). 라우트·DB key는 `a~f`·`gap` 그대로.

| 영역 | 화면 | 반영 |
|---|---|---|
| 검사 목록 | `/hero/hit` 카드·시작 버튼 | 제목 HIT - 이름 · 부제 상황 |
| 검사 소개 | `/hero/hit/a` · `b` · `c` · `d~gap`(StageIntro) | 제목·시작 버튼·선행 검사 안내 |
| 검사 화면 | A 테스트 빈 화면 · G 테스트 머리글 | HIT - Archetype / HIT - Gap |
| 결과 화면 | A·B·C·D~G 공통 헤더 | 제목 HIT - 이름 · 부제 상황 |
| 보고서 | 표지(ReportCover) · PDF 파일명 | `HeRo HIT - Challenger 진입 — … - 준비도 54 - 날짜` |

| 다음 검사 띠 | 결과·보고서 하단 | HIT - 이름 · 상황 |
| 검사 설명 | 모델 가이드(모달·인쇄) — 구조표·생애주기 카드·요약 | HIT - 이름 |
| HIT 엔진 | `/hero/hit/method` | 이름 표기 |
| 나의 저니 | 검사 관리 탭(재편 전 목록 → SSOT로 교체) · 오늘의 미션 · 체크리스트 | HIT - 이름 |
| 마이 · 배지 | HitProfileBadge · 준비 체크리스트 카드 | HIT - 이름 |
| AI 상담 | 선행 검사 안내 · 인사말 · 시스템 프롬프트 라벨 | HIT - 이름 |
| 기타 | 탤런트 에이전시 · 저니 소개 · HIT 프로필 · MADLeague 연결 페이지 | HIT - 이름 |
| 안내 문구 | 서버 오류 안내("HIT - Archetype을 먼저 완료해야 합니다") · 리포트 해석 문구 · Gap 추천 경로 근거 | HIT - 이름 (조사: Archetype·Gap 은/을, 나머지 는/를) |

남김: 개발자 로그(console)·코드 주석의 `HIT A` 표기.
