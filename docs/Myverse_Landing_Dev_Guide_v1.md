# Myverse 랜딩페이지 개발 기획서 (Claude Code용)

> 이 문서는 Claude Code가 읽고 랜딩페이지를 개발하기 위한 기획서다.
> 마지막 업데이트: 2026-03-30

---

## 프로젝트 개요

### 목적
Myverse(Personal Blackbox) 앱 출시 전 Early Access 이메일 수집용 랜딩페이지.
소비자가 페인포인트를 느끼고 → 솔루션을 이해하고 → "깔아봐야겠다"는 마음이 들도록 설계.

### 배포 위치
tenone.biz 하위 페이지 또는 별도 도메인 (myverse.app)

### 기술 스택
- Next.js (tenone.biz 스택과 동일)
- TypeScript
- Tailwind CSS v4
- 별도 백엔드 없음 (이메일 수집은 Supabase `early_access` 테이블에 INSERT)

### 디자인 원칙
- **흑백 모노톤** — Ten:One™ 디자인 시스템. 배경 #0A0A0A, 텍스트 #FAFAFA
- **악센트 컬러**: #FF6B35 (Warm Orange) — 최소한으로, CTA와 강조에만
- **사진이 주인공** — 데모 섹션에서 사진/앱 목업이 유일한 색채
- **장식 없이 깔끔하게** — 타이포와 여백으로 승부
- **폰트**: Noto Sans KR (한국어) + Space Grotesk (영문)
- **애니메이션**: 스크롤 시 fade-in. 과하지 않게. 섹션 진입 시 한 번만.

## 섹션 4: HOW IT WORKS — 3단계

### 카피

```
(섹션 라벨)
HOW IT WORKS

(섹션 타이틀)
나의 흔적이 기록이 된다
```

### 3단계 구조

**Step 1: 기록한다**
```
태그라인: "사진 한 장이면 된다. 나머지는 AI가."

카드 4개:
📷 사진이나 메모를 남긴다     — 찍는 순간, 기록이 시작된다
📅 AI가 캘린더와 대조        — 일정과 기록을 자동 매칭
🏷️ 자동 태그 + LOG 저장     — 장소, 사람, 감정 태그
🌙 하루 요약                — AI가 오늘을 한 줄로 정리
```

**Step 2: 공유한다**
```
태그라인: "내가 원하는 것만, 원하는 사람에게만."

카드 3개:
✨ 나의 기록에서 시작         — 공유할 콘텐츠 선택
🎯 내가 공유하고 싶은 것만    — 원하는 것만 골라서
📤 URL로 어디든 공유         — 카톡, 인스타 DM, 어디든
```

**Step 3: 모은다**
```
태그라인: "흩어진 10년을 한 곳에. 다시는 잃지 않는다."

카드 3개:
🔗 나의 계정을 연결          — 소셜, 클라우드 계정 연동
📥 과거 흔적을 모은다        — 디지털 흔적을 한 곳에
🤖 AI가 관리해준다           — 자동 분류, 정리, 보관
```

### 키비주얼
- 각 Step: 큰 숫자(1, 2, 3) + 제목 + 태그라인 + 카드 그리드.
- 카드: 어두운 배경, 미세한 보더, 좌상단에 이모지 아이콘.
- 숫자는 매우 크게 (4rem+), 회색으로 배경처럼.

### 애니메이션
- 각 Step이 스크롤에 따라 fade-in.

### 키비주얼
- 중앙 정렬. 배경에 미세한 오렌지 radial gradient.

- 인풋: 어두운 배경, 회색 보더, placeholder "이메일 주소".
- 버튼: 흰색 배경, 검정 텍스트, hover 시 살짝 위로.

### 이메일 저장 로직

```typescript
// 신청 시 Supabase에 저장
const { error } = await supabase
  .from('early_access')
  .insert({ 
    email: inputEmail,
    source: 'landing_page',
    created_at: new Date().toISOString()
  });

// 성공 시: 폼 숨기고 "✓ 신청 완료!" 표시
// 실패 시: "이미 신청된 이메일입니다" 또는 에러 안내
```

### Supabase 테이블

```sql
CREATE TABLE early_access (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email TEXT UNIQUE NOT NULL,
  source TEXT DEFAULT 'landing_page',
  created_at TIMESTAMPTZ DEFAULT now()
);

-- 이메일 중복 방지
CREATE UNIQUE INDEX idx_early_access_email ON early_access(email);
```

## 성능 원칙

1. **이미지 최소화** — 대부분 CSS + HTML로 구현. Before/After의 갤러리 목업도 코드로.
2. **폰트 최적화** — Noto Sans KR은 wght 300,400,700,900만 로드. preconnect 사용.
3. **JS 최소화** — 스크롤 fade-in (Intersection Observer), 이메일 폼 제출, 숫자 카운트업만.
4. **First Contentful Paint < 1.5s** — 히어로 텍스트가 가장 먼저 렌더.

## 핵심 원칙 (Claude Code가 기억해야 할 것)

1. **감정 순서를 지킨다.** 공감 → 공포 → 전환 → 방법 → 증거 → 신뢰 → 행동. 이 순서가 뒤바뀌면 전환율이 떨어진다.
2. **FEAR 섹션이 핵심이다.** "32,847장" "170억 건" — 숫자가 공포를 만든다. 이 섹션이 없으면 "나중에 보지"가 된다.
3. **Before/After가 증거다.** 갤러리(날짜만) vs Myverse(태그+감정+요약) 비교가 "뭐가 다른데?"에 대한 즉각적 답이다.
4. **"나는 나의 세계관을 만들기로 했다"가 전환점이다.** 공포에서 희망으로 넘어가는 호흡. 여백을 충분히.
5. **사진이 주인공이 아니다 — 텍스트가 주인공이다.** 이 랜딩은 카피의 힘으로 작동한다. 타이포그래피에 집중.
6. **Ten:One™ 모노톤.** 흑백 기반. 컬러는 오렌지 악센트와 데모 카드의 태그 컬러뿐.
7. **모바일 퍼스트.** 타깃이 스마트폰 사용자. 모바일에서 먼저 잘 보여야 한다.
8. **이메일 수집이 최종 목표.** 모든 섹션은 하단 CTA의 이메일 폼으로 수렴한다.
