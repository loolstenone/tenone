## 2. SmarComm 4주 사용 흐름 — Smart-Loop 7단계 실 매핑

### Week 1 — 진단 + 전략 + 의사결정

**Day 1 월 09:30** — `/smarcomm/scan`에 도메인 입력
- 결과: Index 47점 (D 등급) · F62/T51/C28
- AI 가시성에서 "30대 여드름 흉터 케어 추천" 질문에 자사만 누락
- → 임원진에 캡처 공유

**Day 1 14:00** — `/dashboard/advisor` 12주 캠페인 플랜 자동 생성
- HIGH 사이트 구조 (개발팀) · HIGH 키워드 콘텐츠 (작가) · MEDIUM 보안 헤더
- 예산 ₩3,000,000 자동 산출 → 임원 결재 통과

**Day 2** — `/dashboard/workflow/projects` "글로리아 AI 가시성 12주" 프로젝트 생성
- 7개 태스크 자동 분해 → 칸반의 Backlog
- role별 자동 할당 (개발·작가·디자이너)

**Day 3-4** — `/dashboard/creative` AI 소재 생성
- 카피 5종 + 인스타 배너 3종 → `/dashboard/archive` 영구 저장
- `/dashboard/content`에 블로그 5편 발행 예약

**Day 5** — `/dashboard/campaigns` 광고 집행
- 메타 185만 · 네이버 SA 98만 · 구글 RSA 72만
- `/dashboard/crm/email`로 회원 1,200명 캠페인 메일 발송

**Day 7** — `/dashboard/abtest` A/B 결과로 의사결정
- A 감성형 7.0% vs B 정보형 9.3%
- χ² = 4.8 · p = 0.029 · 95% 신뢰수준 → B 승 (+33.3%)
- "직감" 아닌 **숫자**로 헤로 카피 결정

### Week 2 — 분석 → 다음 액션

**`/dashboard/funnel`** — 랜딩→탐색→참여→**전환에서 1.8% 깔때기 막힘** 발견
**`/dashboard/cohort`** — 1주차 가입자 W2 잔존율 18% 급락
→ 워크플로우에 "체크아웃 단순화·온보딩 메일 4단" 태스크 자동 추가

### Week 4 — AIRM 자동 발견 (매주 월 03:00 cron)

월요일 슬랙 알림: 🚩 AIRM 신규 플래그 3건
- ChatGPT가 3년 전 가격(2만) 답변 (실 4.9만)
- "글로리아 vs SK-II" → 경쟁사만 추천
- "30대 추천 스킨케어" → 글로리아 미언급

### Week 5 — AIRM 교정 액션

`/dashboard/airm/actions` 자동 큐:
- 🎯 마케터 — 보도자료 "정가 정책 발표" (+30 인지)
- ✍️ 작가 — "글로리아 vs SK-II 비교" 콘텐츠 (+20 추천)
- 💻 개발 — Product Schema 갱신 (+15 이해)

→ 30일 후 cron 자동 재진단 → `/dashboard/events`에 ✅ "사실 교정" 기록

### Month 3 — 자산화로 폐쇄

캠페인 12주 종료 시 `/dashboard/assets`에 자동 영속화:

## 5. 미구현·약점 — 시나리오 vs 현실 갭

> ✅ 2026-05-16 30개 메뉴 실 작동 점검 완료. 시나리오 흐름은 대부분 작동.
> 다만 시나리오가 **'완벽히 자연스럽게' 흐르려면** 아래가 필요:

### Critical (시나리오 막힘)

| # | 갭 | 시나리오 영향 | 해결 |
|---|---|---|---|
| C1 | 대시보드 홈 매출/광고 KPI mock | "Day 5 임원 보고" 신뢰성 깨짐 | `wio_campaigns` 실 집계로 교체 + 출처 칩 |
| C2 | Smart-Data Hub tenant_id 'tenone-demo' 기본값 | "집계 실패" 라벨이 사용자에게 항상 보임 | 워크스페이스 tenant_id 자동 매핑 |
| C3 | ANTHROPIC_API_KEY 401 | Advisor·Creative·Insights LLM 미작동 | 키 갱신 (외부 블로커) |
| C4 | ChatGPT·Perplexity·네이버Cue·Google AIO probe stub | 5 AI 플랫폼 시나리오 → 실제는 Claude 1개만 | OpenAI·Perplexity·SerpAPI 키 |

### High (시나리오 어색)

| # | 갭 | 시나리오 영향 | 해결 |
|---|---|---|---|
| H1 | creative 페이지 mock 샘플 데이터 출처 부재 | Day 3 "AI 소재 자동 생성" 진위 의심 | DB 연동 + 출처 칩 |

## 7. 이 문서 활용 규칙

1. **신규 기능 PR 시**: "이 기능이 김지원의 어떤 단계에서 쓰이는가" 명시. 시나리오에 매핑 안 되면 기획 재검토.
2. **신규 페이지 추가 시**: § 2의 4주 흐름에 시나리오 한 줄 추가 (어느 Day·어느 요일·왜 클릭하는지).
3. **시나리오 갱신**: 실 사용자 피드백 누적 시 § 2의 흐름·§ 4의 가치 명제·§ 5의 갭 표 동기화.
4. **§ 5 갭 해결 시**: 해당 row 삭제 + CHANGELOG에 "시나리오 갭 C1 해소" 기록.
5. **새 페르소나 추가 시**: § 6 후보를 § 1처럼 정식 페르소나로 승격.
